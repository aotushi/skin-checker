# ADR 0002:打包范围只锁三端(H5 / 微信小程序 / APK)

- **状态:** 已采纳
- **日期:** 2026-06-16

## 背景

uniapp 支持 H5 / 各家小程序 / App / 快应用 / PC 等多形态;flutter 也可多端。全适配会拖慢"一个月可展示"的节奏。

## 决策

**只锁三端,其余一律不适配、不处理:**

| 端 | 来源 |
| --- | --- |
| H5 | uniapp 编译 |
| 微信小程序 | uniapp 编译 |
| Android APK | flutter 出 APK(uniapp 也可出 App 作双栈对照) |

**明确不做:** iOS(需 Mac + 开发者账号 + 证书)、PC/桌面端、快应用、微信以外其它家小程序。

## 后果

- 按移动端单一布局编写,三端差异仅用条件编译(`#ifdef MP-WEIXIN / H5 / APP-PLUS`)补能力差异(相机、本地存储)。
- 不为未覆盖端做任何响应式或兼容工作。
