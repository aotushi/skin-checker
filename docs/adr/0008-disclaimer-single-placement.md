# ADR 0008:免责声明落点收敛到结果页一处

- **状态:** 已采纳
- **日期:** 2026-07-06

## 背景

初版约定(`CLAUDE.md` 合规文案规则 + `skin-report.schema.json` 的 `disclaimer` 描述)要求**结果页 + 启动页都带**那条 inline 免责声明「本结果由 AI 生成,仅供护肤参考,不构成医疗建议,严重皮肤问题请就医。」

设计迭代中确认:每页重复同一条声明,既挤占版面又稀释注意力。用户拍板 —— 免责收敛到一处展示。

## 决策

那条 inline 免责声明**只在结果页展示一处**:

- **结果页**是最高风险输出(AI 给出的肤质判定 + 护理建议),审核关注点集中于此,声明放这里承载力最强。
- **启动页 / 首页不再强制**带该 inline 声明(此前首页 mockup 已移除)。
- 「我的 → 更多 → 免责声明」是**可点查看的完整声明入口**(法务入口),与那条 inline note 是两回事,保留、不受本决策影响。
- `disclaimer` 字段仍在契约里(结果页渲染它);合规定位「参考 / 建议、不诊断不疗效」不变。

## 理由

- **注意力集中:** 一处强声明胜过多处弱重复。
- **对齐风险:** 声明贴着最高风险的输出页,合规站得住。
- **入口仍在:** 完整声明经「我的」可随时查看,不因收敛而缺失可达性。

备选:维持结果页 + 启动页双带(否决 —— 重复、稀释);完全并入「我的」入口、结果页不 inline(否决 —— 结果页是风险点,必须就地可见)。

## 后果

- ➕ 版面清爽、声明落在风险点、法务入口仍可达。
- ➖ 需同步既有约定:`CLAUDE.md` 合规规则由「结果页+启动页必带」改为「结果页一处」;`skin-report.schema.json` 的 `disclaimer` 描述同步。
- 取代 CLAUDE.md 原「结果页 + 启动页必须带免责声明」条款。
