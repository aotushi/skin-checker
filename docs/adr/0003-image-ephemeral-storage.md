# ADR 0003:用户图片临时存储,用后即删

- **状态:** 已采纳
- **日期:** 2026-06-16

## 背景

核心流程要上传正脸照做多模态分析。人脸图片属敏感数据,长期存储有隐私与合规风险,也增成本。

## 决策

- 上传图片仅用于**单次分析**,分析完成后**不长期存储**:R2 临时对象设过期 / 用后即删。
- 隐私协议明示;历史记录只存**结构化结果**(D1),不存原图。

## 后果

- ➕ 规避 App Store / 广告平台 / 广告法对"医疗"宣称及敏感数据的审核风险;降低存储成本。
- ➖ 无法回看原图(产品定位本就不需要);需在 R2 配生命周期 / 删除逻辑,W1 实现并验证。
