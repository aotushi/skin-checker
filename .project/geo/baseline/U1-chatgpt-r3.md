## 回答摘录(全文)

通常说的"16 型肤质"，指的是皮肤科医生 Leslie Baumann 提出的 Baumann Skin Type（BST）16型肤质系统。它把皮肤放在 4 个二选一的维度上，所以一共是 2^4=16 种组合。正式分类通常通过 Baumann Skin Type Indicator 问卷完成。[Lesliebaumannmd +1]

先看 4 个维度：
O / D — Oily 油 / Dry 干 — 出油量、角质层屏障和保水能力
S / R — Sensitive 敏感 / Resistant 耐受 — 是否容易红、痒、刺痛、长痘或发生炎症
P / N — Pigmented 易色沉 / Non-pigmented 不易色沉 — 是否容易有痘印、晒斑、黄褐斑、炎症后色沉
W / T — Wrinkle-prone 易皱 / Tight 不易皱 — 光老化、皱纹和皮肤老化倾向

这四项组合起来，例如 DSPW = 干性 + 敏感 + 易色沉 + 易老化；ORNT = 油性 + 耐受 + 不易色沉 + 不易皱。[AccessDermatologyDxRx +1]

完整 16 型矩阵：
油+敏感 OS: OSPW / OSPT / OSNW / OSNT
油+耐受 OR: ORPW / ORPT / ORNW / ORNT
干+敏感 DS: DSPW / DSPT / DSNW / DSNT
干+耐受 DR: DRPW / DRPT / DRNW / DRNT

自己怎么粗略判断？

O 还是 D：不要只看鼻子出不出油。更重要的是整体皮肤状态。洗脸后容易紧绷、起皮、缺水，通常偏 D；大部分区域容易油亮、毛孔堵塞、油脂旺盛，更偏 O。Baumann 系统里这一维与皮脂分泌和皮肤屏障都有关。[Lesliebaumannmd]

S 还是 R：如果经常出现护肤品刺痛、泛红、灼热，容易长炎症痘、皮炎或有明显潮红，比较偏 S；很多产品都能用、很少出现红痒刺痛，则更偏 R。所以这里的"敏感"比我们平时说的"敏感肌"范围更广。

P 还是 N：这里最容易误解。P 并不是"肤色深"，N 也不是"肤色白"。它主要说的是"是否容易出现不均匀色素沉着"。比如痘痘消了以后很容易留下深色痘印、容易长晒斑/黄褐斑，通常更偏 P；肤色长期比较均匀、不太容易留下色沉，则偏 N。[AccessDermatologyDxRx]

W 还是 T：也不是简单看"现在有没有皱纹"。它描述的是未来发生皱纹和光老化的倾向。长期日晒、抽烟等因素会增加 W 倾向；T 表示相对不容易出现皱纹。这个维度也会随着年龄和生活方式改变。[PubMed Central (PMC)]

一个很重要的点是：16型肤质并非终身固定。年龄、气候、激素变化、怀孕/更年期、生活方式等都可能使分类发生变化，因此 Baumann 本人建议定期重新评估。[Lesliebaumannmd]
