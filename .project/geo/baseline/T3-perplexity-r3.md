# 回答全文

以下是目前可免费使用的 AI 皮肤状态检测工具，我按「网页在线工具」和「手机 App」两类整理，方便你选择。

网页在线工具（无需下载）

AI Lab Tools 皮肤分析器：上传一张清晰的面部照片即可检测皱纹、痘痘、瑕疵、黑斑、水分含量和整体肤质。免费用户可使用基础分析（皱纹检测、水分分析），升级付费可解锁个性化护肤建议和详细报告。[ailabtools]

旷视 Face⁺⁺ 皮肤分析：可分析皮肤颜色、肤质、眼袋、黑眼圈、皱纹、痘痘、斑点等，分基础版和高阶版，支持上传本地图片或提供图片 URL 体验。[faceplusplus]

Perfect Corp 皮肤分析：可识别 11 个皮肤健康维度，包括斑点、黑眼圈、光泽度、眼袋、泛红、油份、眼皮松弛、水分、紧致度、泪沟等。[perfectcorp]

Vichy SkinConsult AI：与皮肤科医生合作开发的在线工具，上传自拍后分析 7 大皮肤问题（细纹、紧致度、皱纹、毛孔、色素、光泽、眼袋），并生成定制护肤方案。[vichyusa]

手机 App（免费版）

美技 MEDGIC：用 AI 相机拍照，分析皮肤是否干燥、发炎，识别过敏、湿疹、皮炎、色斑、晒伤等常见皮肤问题，并给出建议。[play.google]

AI 肌肤检测（定制护肤方案）：通过深度学习从多维度分析肌肤，包括质地纹理、毛孔粗细、色素沉着、水润光泽度、细纹皱纹、痘痘粉刺等。[apple]

小树美容：3 秒完成皮肤分析，多维度评估光滑度、出油程度、毛孔大小、肤色，含 0-100 分评分和肤龄测算。免费提供 3 次检测机会，且照片默认在本地处理、不上传云端。[apple]

GlowLab：一张自拍即可获得颜值评分、皮肤分析、黄金比例与面部对称洞察，并附免费护肤建议。[play.google]

测肤质：通过手机摄像头分析肌肤纹理、色泽、毛孔大小，评估肤质类型（油性、干性、混合性、敏感性）并指出痘痘、黑头、色斑、皱纹等问题。[qq]

使用提示

免费版通常有次数或功能限制（如小树美容仅 3 次免费检测、AI Lab Tools 基础功能免费），需要完整报告或个性化建议时往往要付费。

检测结果仅供参考，不能替代专业皮肤科医生的诊断，尤其是涉及疑似皮肤病、湿疹或色素病变等情况时，建议线下就医。[play.google]
