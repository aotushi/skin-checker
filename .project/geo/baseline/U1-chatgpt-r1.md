## 回答摘录(全文要点)

通常说的"16 型肤质分类",指的是皮肤科医生 Leslie Baumann 提出的 **Baumann Skin Type(BST)**。用 4 个维度组合,2^4=16 型:

| 维度 | 两端 | 主要看什么 |
|---|---|---|
| 油脂 | O = Oily / D = Dry | 出油量、紧绷脱屑、保湿能力 |
| 敏感度 | S = Sensitive / R = Resistant | 是否容易红、痒、刺痛、长痘、患湿疹/玫瑰痤疮等 |
| 色素倾向 | P = Pigmented / N = Non-pigmented | 晒后、长痘或炎症后是否容易留色斑/痘印 |
| 皱纹倾向 | W = Wrinkled / T = Tight | 光老化、皱纹风险、日晒和生活方式等 |

4 字母代码示例:OSPW / DSNT / ORNT / DRPW。全 16 型:OSPW OSPT OSNW OSNT ORPW ORPT ORNW ORNT / DSPW DSPT DSNW DSNT DRPW DRPT DRNW DRNT。

**怎么判断自己是哪一型?(四步)**
1. O 还是 D:洗脸后不涂护肤品,一段时间后油光/毛孔/粉刺突出偏 O;紧绷起皮粗糙、依赖保湿偏 D(看整体皮脂与屏障,非"T 区偶尔出油")。
2. S 还是 R:常刺痛灼热泛红瘙痒、换品不适、易炎症痘/湿疹/玫瑰痤疮偏 S;多数产品耐受偏 R(Baumann 的"敏感"比日常"敏感肌"范围宽)。
3. P 还是 N:看产生多余色素的倾向(痘印留几个月、易晒斑肤色不均偏 P)。
4. W 还是 T:强调未来老化风险(长期日晒/吸烟/已有细纹松弛偏 W)。

重要限定:**16 型不是永久不变的"皮肤基因身份证"**(季节/年龄/激素/护肤方式/药物/环境会变,冬 D 夏 O,屏障受损暂时更 S);它是**护肤分类框架**而非医学诊断系统,持续泛红脱皮瘙痒痤疮应就医,不能用"我是某某型"代替皮肤科诊断。

结尾:可以直接用 10~15 个问题现场测你的 16 型肤质。
