# 回答全文

想要通过自拍照准确分析肤质（无论是发给专业皮肤科医生、美妆顾问，还是使用AI测肤软件），关键在于还原皮肤最真实的状态。照片拍得越清晰、越客观，分析结果就越准。

请参考以下几个核心技巧来拍摄你的"测肤自拍照"：

1. 拍摄前的准备（准备工作）

卸妆与洁面： 必须彻底卸除彩妆、防晒霜和隔离霜。使用温和洁面产品清洗干净，不要涂抹任何护肤品（水、乳、面霜、精华都不要涂，以免亮光或成膜影响判断）。

等待 15–20 分钟： 洁面后先不要拍照，等待 15 分钟左右。这样能让皮肤恢复自然的油脂分泌和水分平衡状态，便于观察真实的油腻程度或干燥脱皮情况。

露出一整张脸： 用发带或发夹将刘海和碎发全部固定在脑后，露出额头、鬓角和下巴。摘掉眼镜、耳环等饰品。

2. 光线选择（最重要的决定因素）

首选：自然散光（推荐）

白天站在靠近窗户、但没有阳光直射的位置（室内明亮的自然光）。

避开强烈的直射太阳光（会导致阴影重、过度曝光），也避开暗光环境。

避开死亡灯光：

切忌顶光： 如卫生间或房间正上方的吊灯，会形成巨大的眼袋和面部阴影，让人看起来虚假衰老。

切忌黄光/暖色光： 会严重遮盖面部泛红、痘印或斑点。

切忌美颜补光灯： 自带打光和柔肤效果，会磨平真实纹理。

3. 设备与拍照设置

使用后置摄像头： 手机的前置摄像头通常分辨率较低且默认带有一点"微美颜"。强烈建议使用手机后置主摄，可以用镜子辅助对焦，或者请朋友帮忙拍摄。

关闭所有美颜和滤镜： 确保相机设置中的原相机美颜、滤镜、HDR或夜景模式全部关闭。

擦拭镜头： 拍摄前用眼镜布或柔软纸巾把手机镜头擦干净，防止上面的油脂让画面发糊。

4. 角度与姿势

正对镜头，视线平视： 保持头部端正，眼睛平视前方，不要仰头或低头，防止产生虚假的面部下垂或皱纹。

表情自然放松： 保持无表情（面无表情）状态，不要咧嘴笑、贴眉或噘嘴，这样更容易观察静止纹（如法令纹、抬头纹）和毛孔分布。

拍摄多角度组合：

正脸照： 观察整体肤色均匀度、出油/干燥区域、痘痘分布。
左右侧脸 45° 照： 观察侧脸毛孔、闭口、痘印及面部轮廓。
局部特写（可选）： 针对你最关心的区域（如鼻翼两侧的毛孔、眼周细纹或眼下色素沉积）单独近距离拍一张清晰的照片。
