## 回答摘录(全文)

可以。干皮痘肌最适合的不是"猛祛痘",而是「温和清洁 + 足量保湿 + 一个祛痘核心成分 + 防晒」。祛痘成分本身往往会增加干燥和刺激,所以保湿对痘肌反而很重要。[AAD +1]

我会把品类搭配成下面这样:

| 品类 | 建议 | 选什么方向 |
|---|---|---|
| 洁面 | 必备 | 温和、低刺激、不追求洗完"涩" |
| 化妆水/精华水 | 可有可无 | 单纯补水舒缓即可,不建议拿它刷酸 |
| 祛痘精华/药膏 | 选1个核心 | 壬二酸 / 阿达帕林 / 过氧化苯甲酰,根据痘型选 |
| 保湿霜 | 非常重要 | 甘油、神经酰胺等保湿修护型,偏乳霜质地也没问题 |
| 防晒 | 必备 | SPF 30+、广谱,优先标注不易堵塞毛孔/Non-comedogenic |

**最简单的一套**

早上:温水或温和洁面 → 补水精华(可省) → 保湿乳/霜 → 防晒

干皮如果早晨几乎不出油,甚至不一定需要用洁面产品,避免一天洗得太狠。痘肌也不需要磨砂、洁面仪或者"深层清洁"才能洗干净,刺激过度反而可能让痘更糟。[AAD]

晚上:温和洁面 → 祛痘产品 → 保湿霜

关键是中间这一层不要同时塞三四个活性成分。

**祛痘产品怎么选**

如果你是闭口、白头、黑头比较多,优先考虑阿达帕林这类维A酸类。它对疏通毛孔、预防新痘的证据比较强,但对干皮也比较容易产生脱皮、紧绷,所以可以从每周2晚左右慢慢建立耐受,薄涂全脸痘区,而不是厚厚点涂。皮肤容易干的话,可以采用:

保湿霜 → 阿达帕林 → 保湿霜

这种"夹心"思路降低刺激。AAD也建议容易受到维A酸刺激的人减少使用频率、配合保湿。[AAD +1]

如果你是红肿痘、炎症痘比较多,可以考虑过氧化苯甲酰(BPO),它主要针对炎症和痤疮相关细菌。问题同样是比较容易干,所以干皮不建议一开始大面积、高频使用。[AAD +1]

如果你属于又干、又敏感,同时有痘印/红痘,我反而比较建议先看壬二酸。它兼顾毛孔堵塞、炎症和痘后色沉,相比猛刷酸通常更容易和干皮的保湿体系搭配。[AAD]

至于水杨酸,不是不能用,但干皮痘肌通常不需要把"水杨酸爽肤水 + 水杨酸精华 + 清洁面膜"做成日常套餐。它能帮助疏通毛孔,但本身也可能增加干燥刺激;如果要用,更适合低频、局部,而不是每天刷。[AAD]

**我尤其不建议你这样搭**

比如晚上:皂基/强清洁 → 水杨酸水 → 酸类精华 → 阿达帕林 → 控油乳

对油皮都可能刺激,对干皮痘肌尤其容易把屏障搞得又红、又干、刺痛脱皮。

更好的原则是:一个晚上一个主要祛痘思路,其余全做保湿。

例如你用阿达帕林,就先别同时加果酸、水杨酸和高浓度祛痘精华;耐受稳定以后再判断有没有必要增加其他东西。

如果目前已经有洗完脸紧绷、护肤刺痛、起皮、泛红,建议先暂缓大部分功效成分,做一段时间:温和洁面 + 保湿霜 + 防晒。等皮肤舒服以后,再一个一个加入祛痘成分。

另外,选乳液、面霜和防晒时,可以优先找包装上写有 "non-comedogenic / won't clog pores / 不易致痘" 的产品。痘肌并不等于必须使用清爽啫喱,干皮完全可以用滋润一些的面霜。[AAD +1]

如果你正在备孕或怀孕,不要自行用阿达帕林等维A酸类;AAD建议孕期停用这类成分,壬二酸通常是孕期更常考虑的选择,但仍建议和医生确认。[AAD +1]

如果你愿意告诉我你主要是 闭口 / 黑头 / 红肿痘 / 脓包 / 下巴周期痘 哪一种,以及大概预算,我可以直接给你配成一套「洁面—精华—祛痘—面霜—防晒」的具体品类组合。
