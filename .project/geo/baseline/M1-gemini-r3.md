# 回答全文

判断自己的肤质其实很简单，最有效、最直观的方法就是"洗脸观察法"。找一个不需要出门的周末或晚上，按下面的步骤操作即可：

第一步：测一测（洗脸观察法）

温和清洁：用温水和温和的氨基酸洗面奶把脸洗干净。

保持素颜：洗完脸后，不要擦任何护肤品（水、乳、霜都不涂）。

静置等待：在温度适宜的室内静坐 30~60 分钟。

观察感受：时间到后，照镜子并感受脸部的变化：

第二步：对照结果看肤质

| 肤质类型 | 30~60 分钟后的面部表现 | 典型特征 |
|---|---|---|
| 油性肌肤 (油皮) | 全脸（包括额头、鼻子、两颊、下巴）开始明显冒油、发亮。 | 毛孔粗大、易长粉刺痘痘、容易脱妆。 |
| 干性肌肤 (干皮) | 全脸感觉紧绷、干燥，甚至伴随局部脱屑、发痒。 | 几乎不冒油，毛孔细小，但容易产生细纹、皮肤干瘪。 |
| 混合性肌肤 (混合皮) | T区（额头、鼻子、下巴）冒油发亮，但两颊干燥紧绷或感觉舒适。 | 兼具油皮和干皮的特征，也是最常见的肤质。 |
| 中性肌肤 (健康皮) | 不油也不干，皮肤舒适、细腻有弹性（"天选之子"）。 | 水油平衡，极少长痘或出油，状态非常稳定。 |

吸油纸辅助小技巧：
如果用肉眼很难判断，可以在洗脸 1 小时后，拿几张吸油纸轻轻按压额头、鼻子、两颊和下巴。

全纸透明 → 油皮
全纸无油 → 干皮
只有T区透明，两颊无油 → 混合皮

💡 补充提示：分清"混合偏油"与"混合偏干"

混合皮还可以细分，这有助于你更精确地选择护肤品：

混油皮：T区油光非常明显，两颊不干不油（或微油）。
混干皮：T区微微出油，但两颊紧绷甚至起皮。

另外需要注意，肤质不是一成不变的，它会随季节（夏油冬干）、年龄、生理期以及环境湿度发生变化。
