# 回答全文

这是典型的混合型皮肤（俗称"混油皮"或"混干皮"）。

为什么会这样？

你的面部皮脂腺分布不均：

T区（额头、鼻子、下巴）： 皮脂腺密度高、分泌旺盛，容易出油、冒黑头或长痘。

脸颊两侧： 皮脂腺较少，水油不平衡，容易干燥、紧绷甚至脱皮。

如何判断是"混油"还是"混干"？

混合偏油（混油）： T区油光明显，脸颊只是正常或微干，夏天整体更偏油。

混合偏干（混干）： T区只是微微出油，但脸颊明显干燥、紧绷，冬天脱皮感更强。

护理的核心思路：分区护理，水油平衡

清洁：温和为主
使用氨基酸洁面，避免过度清洁。洗脸时重点揉搓 T 区，脸颊轻轻带过即可。

保湿：分区涂抹
T区： 使用轻薄清爽的水乳或精华，避免滋润型霜类堵塞毛孔。
脸颊： 使用保湿力较强的乳霜，及时补充水分和面霜锁水。

防晒：选清爽型
优先选择质地清爽、不闷痘的防晒霜，避免加重 T 区负担。
