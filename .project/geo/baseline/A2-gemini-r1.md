## 回答摘录(全文)

干皮但长痘(俗称"干痘肌")其实非常普遍!这种情况往往是因为皮肤屏障受损、水油失衡或局部角质堆积导致的,属于典型"脆弱又欠通"的皮肤状态。

护肤品搭配的核心逻辑是:温和清洁 + 基础保湿修护 + 局部/低浓度精准祛痘。千万不要全脸盲目控油打祛痘刷酸,否则会越来越干、痘痘反而更多。

### 护肤品类搭配架构

**1. 晨间护肤(精简防护)**——重点:维持水油平衡 + 抗氧化防晒

| 品类 | 选品建议 & 避坑点 |
|---|---|
| 温和洗面奶 | 纯氨基酸洗面奶(或早上直接温水洗脸);❌ 严禁皂基、深层清洁洗面奶 |
| 保湿舒缓水/喷雾 | 成分简单、含 B5(泛醇)、积雪草等修护成分 |
| 轻薄精华 | 玻尿酸、B5 或积雪草精华补水 |
| 乳液/轻薄面霜 | 神经酰胺、角鲨烷成分修护乳液;避免过厚重的大油霜 |
| 防晒霜 | 纯物理防晒或清爽型化学/混合防晒(标注无致痘性/Non-Comedogenic) |

**2. 晚间修护与祛痘(分区精细化)**——流程:温和卸妆/清洁 → 水/修护保湿精华(全脸) → 轻润肤乳/霜(全脸,避开大面积痘痘或薄涂) → 精准祛痘点涂(仅患处)

| 品类 | 选品建议 & 避坑点 |
|---|---|
| 卸妆产品 | 温和卸妆水或不致痘卸妆膏,避免黏腻致痘的植物油 |
| 修护类精华 | 神经酰胺、依克多因、B5,先打好屏障底子 |
| 祛痘功效品 | **只局部点涂**!红肿脓包痘:壬二酸(15%)、过氧苯甲酰、皮肤科开的夫西地酸;闭口/粉刺:水杨酸(1-2%)棉片点敷;温和抗炎:泛醇+积雪草+水杨酸复配 |
| 修护面霜 | 不含致痘油脂(可可脂、高浓度异棕榈酸酯);干区厚涂,痘痘区避开或极薄涂 |

### 避坑与实操避雷指南(核心原则:温和第一,分区对待)

- **全脸保湿,局部祛痘**:刷酸或祛痘膏只涂有痘和闭口的地方,千万不要全脸大面积刷酸,否则干皮直接脱皮爆痛。
- **避开高致痘成分**:异丙酯类(IPM/IPP)、高浓度椰子油、可可脂等重油成分。
- **修护先行**:皮肤发红、刺痛时先暂停一切祛痘酸类,用 3~5 天纯保湿修护(神经酰胺+B5),屏障恢复后再局部祛痘。
- **注意精简**:叠加层数不超过 3~4 层,干痘肌最怕"闷"和"刺激"。

(结尾追问:干痘肌具体的成分黑名单与红榜 / 红肿痘与闭口粉刺的具体用药搭配)
