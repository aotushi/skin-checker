# 回答全文

判断自己属于油皮、干皮还是混合皮，最可靠的方法是清洁后观察法（裸脸测试），配合吸油纸法和触感观察。下面给你一套在家就能做的判断流程。

核心方法：清洁后观察法

这是医生最推荐的判断方式，具体操作如下：[news.cctv]

用温和的洗面奶洗脸，清水冲净

用干净毛巾把水吸干（不要擦）

什么都不涂，等待一段时间再观察面部状态

不同肤质的判断标准：

| 肤质 | 洁面后的表现 | 紧绷感消失时间 |
|---|---|---|
| 油性 | 全脸泛油光，尤其额头、鼻翼有明显油光、毛孔粗大 | 约20分钟 |
| 干性 | 全脸干燥、紧绷，甚至有小脱皮细屑 | 约40分钟以上 |
| 中性 | 光滑细嫩、不油不干 | 约30分钟 |
| 混合性 | T区（额头、鼻子、下巴）泛油光，但两颊（U区）偏干紧绷 | 分区表现不同 |

其中，判断混合皮的关键是分区观察：如果T字区泛油光，而两颊比较干，就属于混合性肌肤。[news.cctv +1]

辅助方法：吸油纸法

用吸油面纸轻轻按压额头、鼻子、两颊和下巴，观察出油情况：[dr-once]

油皮：全脸吸油纸上油脂都很多

干皮：几乎吸不到油，皮肤还觉得干、绷

混合偏油：油脂集中在T字部位，脸颊较清爽

混合偏干：油脂集中在T字部位，脸颊干燥无油

触感与观察法

在自然光下用指尖轻触皮肤：[dr-once]

偏油：整脸滑滑、油腻，毛孔明显

偏干：摸上去干燥、紧绷，可能有干纹或脱屑

混合：T区油腻、毛孔大，两颊却干燥紧绷[sohu]

混合皮还要细分

混合性肌肤通常分为两类：[sohu]

混干皮：T区出油、毛孔粗大，但两颊紧绷干燥、水分油分都少，眼周可能有干纹

混油皮：T区出油多、毛孔粗大、易长小痤疮，但两颊不油也不干，偏中性

判断后的护肤建议

油皮：重点控油、保持毛孔通畅，避免油炸和刺激性食物[lalabeautyplus]

干皮：注重补水保湿，加强屏障修复

混合皮：需要分区保养——T区用控油或含水杨酸（BHA）的产品，两颊用含玻尿酸或神经酰胺的保湿霜；白天控油、晚上保湿效果最好[dr-once +1]

小提示：判断肤质最好在早上刚起床、还没洗脸时观察，或洗完脸后不涂任何护肤品等到下午再看，这样结果更准确。另外，超过25岁后中性皮肤较少，大多数人主要属于油性、干性或混合性。[news.cctv +1]
