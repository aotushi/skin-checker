# 回答全文

干皮还会长痘（通常被称为"干痘肌"），本质上是因为皮肤屏障受损或局部油脂分泌异常/角质排泄不畅造成的。

很多干痘肌最容易犯的错误就是疯狂使用控油抗痘产品，结果把皮肤屏障彻底撕裂，导致"越干越痒，越补越痘"。

针对干痘肌，精简且精准的护肤品搭配公式为：温和清洁 + 精准祛痘/温和刷酸 + 屏障修护/水油平衡 + 纯物理/清爽防晒。

推荐搭配方案（分早晚）

晨间护肤：水油平衡 + 防晒防护

| 步骤 | 品类推荐 | 选品考量与建议 |
|---|---|---|
| 1. 清洁 | 清水 或 温和氨基酸洁面 | 干皮早上如果脸不油，直接用温水冲洗即可；如果 T 区出油，局部用无泡沫/低泡氨基酸洁面。 |
| 2. 补水/舒缓 | 无油/清爽型保湿水 | 挑选含有泛醇（B5）、积雪草、马齿苋等成分的舒缓水，避开高浓度酒精和重油分。 |
| 3. 保湿 | 轻薄型乳液 / 啫喱面霜 | 选择神经酰胺、角鲨烷、玻尿酸等修护保湿成分，避开致痘风险较高的矿物油、异丙脂类成分。 |
| 4. 防晒 | 纯物理防晒 或 敏感肌专研防晒 | 紫外线会加重炎症和痘印。尽量选择物理防晒霜，或氧化锌/二氧化钛复配的清爽型防晒，减少刺激。 |

晚间护肤：精准抗痘 + 屏障修护

晚间是修护和调理的最佳时机，采用"分区护理"策略最有效。

| 步骤 | 品类推荐 | 选品考量与建议 |
|---|---|---|
| 1. 卸妆/清洁 | 温和卸妆水 / 卸妆膏 + 氨基酸洁面 | 如果化了彩妆，避开容易致痘的卸妆油；若只用了防晒，用温和洁面即可。洗完后脸部不应有紧绷感。 |
| 2. 祛痘调理 (分区) | 低浓度水杨酸/壬二酸 或 点涂祛痘精华 | 重点：不要全脸刷酸！• 红肿脓包痘：点涂壬二酸（15%左右）或班赛（过氧化苯甲酰，需建立耐受）。• 闭口/黑头：局部点涂 0.5%~1% 的水杨酸。 |
| 3. 保湿修护 | 修护型面霜 | 避开酸类产品的区域全脸涂抹；待祛痘成分吸收后，在全脸（包括长痘区）薄薄涂一层角鲨烷/神经酰胺修护面霜，防止干脱皮。 |

避坑指南：干痘肌的"三要三不要"

三要：
要分区对待：出油/长痘的区域用祛痘产品，干燥无痘区域做好保湿修护。
要注重修护：修护好皮肤屏障（补充神经酰胺），痘痘往往会自动好转一半。
要做好精简：叠加超过 4 种护肤品只会加重皮肤负担。

三不要：
不要全脸大面积刷酸/控油：这会让干皮瞬间变成敏感肌，引发爆发性长痘。
不要使用强力皂基洁面：洗完脸"嘎吱响"的洁面乳一律丢掉。
不要使用过于厚重的封闭性油脂：如高浓度羊毛脂、纯矿物油等，极易闷出闭口。
