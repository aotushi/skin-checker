# 回答全文

市面上有不少在线 AI 测肤工具，多数是拍照上传后由算法分析肤质、肤龄、皱纹、色斑、毛孔、痘痘等维度，并给出护肤建议。以下是几类常见选择：

面向普通用户的在线测肤工具

AILab Tools（AI 皮肤分析）：网页版工具，上传清晰面部照片即可实时检测皱纹、黑斑、水分、瑕疵和整体肤质，几秒到几分钟出结果，可下载个性化皮肤报告并获取护肤建议。[ailabtools]

ELIXIR 怡麗絲爾 AI 線上肌膚檢測（watashi+）：资生堂集团开发，可检测脸部不同部位的松弛、纹路、斑点等 16 个项目，并生成「水玉光图表」和专属护肤建议。[shiseido]

美丽修行 APP：与旷视 FaceStyle 合作上线了「AI 拍照测肤」，几秒钟即可分析毛孔、痘痘、黑眼圈、色斑等，并解析肤龄和得分；同时提供干性/油性、敏感/耐受、色素/非色素、皱纹/紧致四类问卷测试，还能推荐护肤产品。[bebd.bevol]

面向品牌/商家的解决方案

旷视 FaceStyle（Face⁺⁺）：提供移动端 SDK、API、H5 接入，涵盖干油性、敏感度、色素沉着、衰老、痤疮等分析，供护肤品牌和零售商家做数字化营销。[faceplusplus]

玩美移动（Perfect Corp）AI 测肤：由深度学习算法驱动的实时皮肤检测，面向企业提供皮肤分析和产品推荐方案。[perfectcorp]

美图 AI 开放平台：提供「准医学级别」的智能测肤 API，分析维度包括肤质、肤色、肤龄、痘、斑、痣、皱纹、黑眼圈、毛孔、黑头等，肤色按国际标准分为 40 级。[meitu]

宜远智能（美肤镜）、肌肤管家 SkinRun Lab 等也提供在线拍照测肤及 API 服务。[yiyuan +1]

使用提示

在线测肤主要基于照片分析，结果仅供参考，不能替代皮肤科医生的专业诊断。

拍照时尽量在光线均匀的环境下、素颜、正对镜头，结果会更准确。

不同工具的评分维度和算法不同，同一张照片在不同平台的结果可能有差异，可多试几个对比。

如果你想要的是「上传照片就能出报告」的免费网页版，AILab Tools 是最直接的入口；如果想要更全面的肤质问卷+拍照结合，可以试试美丽修行 APP。[ailabtools +1]
