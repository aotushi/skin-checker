# 回答全文

想知道自己的皮肤是不是"敏感肌"，其实不用复杂的仪器，通过观察日常的皮肤反应、外观状态和主观感受，就能做一个初步的自测。

你可以对照以下几个维度梳理一下：

1. 核心判断标准（符合项越多，敏感概率越高）

对外界刺激反应过敏捷： 稍微吹风、晒太阳、换季，或者换用新的护肤品时，脸部就会迅速出现发红、发烫、刺痛、紧绷或瘙痒的感觉。

耐受度极低： 使用含有酒精、高浓度酸类（如果酸、水杨酸）、维A醇或高浓度香精的产品时，反应剧烈，甚至连用基础的保湿产品都有刺痛感。

肉眼可见的屏障受损： 脸颊部位角质层薄，能看到明显的红血丝（毛细血管扩张），或者经常无故局部泛红、脱皮、起小红疹。

极易受环境影响： 进出空调房、吃烫/辣的食物、或者情绪激动时，脸部温度会迅速升高并明显发红，且久久不能退去。

2. 简易自测小实验：爪抓法（皮肤划痕反应）

用干净的指甲背或钝头小棒，在手臂内侧或脸颊边缘轻轻划一条线。

正常皮肤： 出现短暂的微红，几分钟内就会消退。
敏感/高反应性皮肤： 划痕处迅速变红、隆起，并伴有明显痒感或刺痛，且红印持续较长时间不退。

3. 常见误区澄清

注意区分："敏感肌" vs "过敏" vs "单纯干到刺痛"

敏感肌是一种皮肤状态： 意味着你的皮肤屏障功能比较脆弱，抗刺激能力差，属于长期或阶段性的状态。

过敏是一种免疫反应： 通常是对某种特定成分（如某种植物提取物、防腐剂）产生的突发性红肿、起荨麻疹，属于偶然事件。

单纯干燥导致的刺痛： 如果你平时皮肤很好，只有在极度干燥的秋冬季节涂水乳时刺痛了一下，补足水就不痛了，这通常只是皮肤缺水导致的假性敏感，不代表你是敏感肌。

4. 初步判断后的建议

如果怀疑自己是敏感肌： 护肤原则立刻精简为 "温和清洁 + 基础保湿 + 物理防晒"，暂停所有功效型产品（美白、抗老、去角质、刷酸）。

如果红肿、刺痛严重且持续不退： 建议直接寻求皮肤科医生的帮助，排除皮肤炎、玫瑰痤疮等病理因素。
