# 回答全文

16 型肤质分类（又称鲍曼肤质分类法，Baumann Skin Typing System）是由美国著名皮肤科医生莱斯利·鲍曼（Dr. Leslie Baumann）提出的。 [lumino.skin]

传统肤质划分（干性、油性、混合性、中性）过于简单，无法全面反映皮肤敏感度、色素变异或衰老状态。鲍曼医生将皮肤的 4 种核心维度 进行两两组合，衍生出 16 种精准的肤质类型。这就好比护肤届的 "皮肤 MBTI"。 [AKIMIA]

一、 它是怎么分的？（4 大核心维度）

鲍曼分类法从以下 4 个维度判断皮肤状态，每个维度取一个代表字母：

1. 油水平衡维度：干性（D） vs 油性（O） [问卷星]
D（Dry）干性： 出油少，洗脸后常有紧绷感、易起皮脱屑，毛孔不明显。 [问卷星]
O（Oily）油性： 皮脂分泌旺盛，容易出油、冒痘，毛孔较粗大。 [问卷星]

2. 敏感耐受维度：敏感性（S） vs 耐受性（R） [AKIMIA]
S（Sensitive）敏感性： 屏障功能较弱，换季或使用刺激性成分时容易泛红、刺痛、发痒或长疹子。 [问卷星 +1]
R（Resistant）耐受性： 皮肤屏障坚固，极少过敏或刺痛，对各类成分适应度高。 [问卷星]

3. 色素沉着维度：色素沉着性（P） vs 非色素沉着性（N） [AKIMIA]
P（Pigmented）色素沉着： 容易长斑、晒黑，且痘印、伤口愈合后极易留黑印（炎症后色素沉着）。 [lumino.skin]
N（Non-pigmented）非色素沉着： 不易长斑，晒后更易发红而非变黑，痘印退得快。 [lumino.skin]

4. 衰老程度维度：皱纹性（W） vs 紧致性（T） [lumino.skin]
W（Wrinkled）皱纹/易衰老： 已出现细纹、松弛，或因长期晒太阳、抽烟熬夜导致衰老风险高。 [PubMed]
T（Tight）紧致： 皮肤弹性好、紧致度高，细纹少。 [lumino.skin]

二、 组合出来的 16 种肤质类型 [问卷星]

将上述 4 个维度的字母按顺序组合，就能得到你专属的 4 字母肤质代码： [lumino.skin]

| 代码类型 | 组合全称 | 常见特征与护肤侧重 |
|---|---|---|
| DSPT / DSPW | 干敏色素紧致 / 皱纹型 | 保湿、修护屏障为主，兼顾美白提亮和防晒。 |
| DSNT / DSNW | 干敏非色素紧致 / 皱纹型 | 典型敏感肌，需全力舒缓抗敏、补水保湿。 |
| DRPT / DRPW | 干耐色素紧致 / 皱纹型 | 吸水差但屏障好，适合高浓度酸类或美白成分。 |
| DRNT / DRNW | 干耐非色素紧致 / 皱纹型 | 皮肤省心，只需做好日常基础保湿和抗老。 |
| OSPT / OSPW | 油敏色素紧致 / 皱纹型 | 最复杂的肤质之一，既要控油清痘、又要舒缓退红、还要淡印。 |
| OSNT / OSNW | 油敏非色素紧致 / 皱纹型 | 俗称"油敏肌"，重点在于控油的同时温和修护。 |
| ORPT / ORPW | 油耐色素紧致 / 皱纹型 | 俗称"大油皮兼斑点肌"，适合酸类控油及强效美白。 |
| ORNT / ORNW | 油耐非色素紧致 / 皱纹型 | 俗称"城墙油皮"，耐受度极高，适合各类高效活性成分。 |

三、 了解 16 型肤质有什么用？

避免"盲目跟风"： 比如同样是油皮，如果你是 OSNW（油敏），盲目跟着 ORNT（油耐） 的刷酸攻略走，可能会导致烂脸。

精准选择成分： 知道自己是否带有 S（敏感）或 P（色素沉着），能帮你迅速避开致敏源或精确定位美白成分。

动态调整护理： 人的肤质不是一成不变的。例如随着年龄增长或季节变化，你可能会从 T（紧致） 变成 W（易老），或者从 O（油） 变成 D（干）。 [AKIMIA]
