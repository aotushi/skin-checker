## 回答摘录(全文)

干皮又会长痘，核心不是"控油控到干"，而是先把屏障和保湿做好，再用少量、低频的祛痘成分。品类不用堆很多，基础可以控制在 4–5 类。

早上：温和清洁/清水 → 保湿精华 → 面霜 → 防晒。清洁选温和、低刺激、洗完不紧绷的洁面，不必追求"深层清洁""强控油"。保湿精华可以看甘油、透明质酸、泛醇、β-葡聚糖这类；面霜更建议有神经酰胺、胆固醇、脂肪酸、角鲨烷等屏障脂质。防晒选自己愿意每天用、不会明显拔干或闷痘的即可。

晚上：温和洁面 → 祛痘产品 → 保湿面霜。祛痘成分不要一次上很多，优先从一种开始：

如果主要是闭口、黑头、毛孔堵塞：可以选低浓度水杨酸，先每周 1–2 次。

如果是反复长粉刺和痘痘：阿达帕林通常比单纯刷酸更针对痤疮，但干皮更容易刺激，建议从每周 2 次左右、少量开始；可以用"面霜 → 阿达帕林 → 面霜"的夹心法减轻干燥。

如果主要是红肿痘：过氧化苯甲酰可以局部或低频使用，但也比较容易干，别和一堆酸同时叠加。

干痘皮尤其建议少买几个"功能型精华"。烟酰胺可以有，但不必追求 10% 甚至更高浓度，2%–5%通常已经够用；果酸、水杨酸、A醇/维A类、清洁面膜、磨砂膏不要一起堆，很容易变成"痘没好，屏障先坏了"。

你可以直接按这个搭配：

洁面—温和型，晚间一次为主 / 补水精华—可选，不是必须 / 修护面霜—必备，干皮重点 / 祛痘产品—只选1个主力成分起步 / 防晒—每天必备 / 清洁面膜/磨砂—基本不需要

还有一个比较实用的判断：如果用了祛痘产品之后持续刺痛、脱皮、泛红，先减少频率，不要再加更强的酸。对干皮来说，"用得久"往往比"用得猛"更重要。

如果你告诉我你现在主要是闭口、红肿痘、下巴反复长，还是痘印为主，以及你现在已经在用哪些护肤品，我可以直接帮你配成一套早晚护肤品类清单，并告诉你哪些东西没必要买。
