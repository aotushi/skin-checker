# 回答全文

这四个维度来自美国皮肤科医生 Leslie Baumann 提出的鲍曼皮肤分型（Baumann Skin Type），把肤质拆成四组基本要素，每组两个选项，组合成 16 种肤质类型。 你问的"油脂、敏感、痘痘、色沉"对应的是其中几个核心维度：[yjj.scjgj.fujian +1]

各维度含义

油脂（油性/干性）
指皮脂腺分泌旺盛程度。油性皮肤皮脂分泌多、毛孔粗大、易泛油光，容易长黑头、闭口、粉刺和痘痘，但不易长皱纹；干性皮肤则油脂不足、易干燥缺水。[yjj.scjgj.fujian +1]

敏感（敏感/耐受）
指皮肤对刺激的耐受程度。敏感肌皮肤屏障较弱，接触日光、冷热、化妆品等刺激后易出现泛红、刺痛、瘙痒、丘疹，甚至红肿，对香料、酒精、酸类等成分特别敏感。 敏感可以叠加在任意肤质上（如"油性敏感肌""干性敏感肌"）。[dxy +1]

痘痘（痘痘肌）
严格来说痘痘并不是一种独立"肤质"，而是一种由多种因素引起的皮肤状态——包括荷尔蒙、作息、清洁不当、细菌感染、气候和过敏原等，表现为反复出现的粉刺、闭口、暗疮。 它常与油脂分泌旺盛、毛孔堵塞密切相关。[yjj.scjgj.fujian +1]

色沉（色沉型/非色沉型）
指皮肤发生色素沉着（色斑、痘印变黑等）的倾向。当皮肤发炎或受日晒刺激时，黑色素细胞被激活，在表皮或真皮产生色素，形成色斑或炎症后色素沉着（如红色痘印转为黑印）。 是否容易留印、长斑，很大程度上取决于个人体质。[ai-beauty]

组合方式

每组二选一就形成 16 种组合，类似肤质版的"MBTI"，例如"油-敏-色沉-易皱"（O-S-P-W）这类类型，容易长痘、泛红、发炎后留色素且早期有光老化风险。[yjj.scjgj.fujian +2]

简单说：油脂看皮脂分泌多少，敏感看耐受程度，痘痘看是否易长痘的皮肤状态，色沉看是否容易留印长斑——这四者共同决定你的肤质画像和护理重点。[yjj.scjgj.fujian +1]
