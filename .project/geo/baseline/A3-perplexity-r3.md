# 回答全文

混合皮（T区偏油、两颊偏干）选防晒的核心是：既要控油不闷痘，又要保湿不拔干，所以质地和肤感往往比单纯的防晒值更重要。以下是几个关键注意点。

选对质地与肤感

混合皮最容易踩的坑是"要么太油闷痘、要么太干起皮"。 建议优先选清爽的乳液、凝露或摇摇乐质地，避免厚重油腻的霜状产品，这类更容易堵塞T区毛孔。 肤感上追求"轻薄、不假白、成膜快"，这样才愿意天天坚持涂。[finance.sina +3]

看准防晒力

选择广谱防晒，即同时防护 UVB 和 UVA，标签上有 SPF 值和 PA 等级（或标注"广谱"）。[nmpa +1]

日常室内用 SPF 30 即可，长时间户外建议 SPF 50 或更高、PA++++ 的防水防汗配方。[skincancer +1]

注意：SPF 和 PA 不是越高越好，数值越大通常意味着防晒剂含量越高、成分越复杂，可能加重皮肤负担，应根据场景选择。[nmpa]

关注附加成分

混合皮可以挑一些带"加分项"的配方：

烟酰胺：帮助调节皮脂分泌、强化屏障，适合油性区域。[joybuy]

积雪草（Cica）：舒缓，适合两颊偏干或敏感区域。[joybuy]

敏感肌可选物理防晒剂（氧化锌、二氧化钛），引起刺激的可能性更低。[skincancer]

使用与清洁

用量要足（约 2 mg/cm²，面部约一枚硬币大小），出门前 15–30 分钟涂，户外每 2–3 小时补涂一次。[nmpa +1]

顺序：基础护肤后、彩妆前使用。[nmpa]

清洁：轻薄不防水的可用洗面奶洗掉；防水防汗型需用卸妆产品，避免残留堵塞毛孔。[nmpa]

新换防晒前，最好在手臂内侧或耳后试涂 72 小时，确认无红肿、痒等反应再上脸。[nmpa]

一句话总结

混合皮选防晒 = 清爽不油腻的质地 + 广谱高倍防护 + 适量保湿，并根据当天场景（室内/户外）调整 SPF，同时注意足量涂抹和正确清洁。
